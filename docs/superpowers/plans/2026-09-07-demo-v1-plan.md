# OS Empresa Demo V1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Entregar uma demo privada e funcional do OS Empresa, instalada como uma pasta e pronta para um amigo testar com Claude Code ou Codex.

**Architecture:** A pasta contém dados do negócio, clientes, projetos e entregas em Markdown com frontmatter YAML. Skills canônicas ficam expostas por adaptadores leves ao host do agente; nenhuma dependência externa é necessária para o núcleo. Um instalador PowerShell/Bash cria a estrutura, um validador testa contratos e os packs de vídeo/anúncios ficam documentados como opcionais.

**Tech Stack:** Markdown, YAML frontmatter, PowerShell 7+, Bash, Git, Claude Code skills, Codex `AGENTS.md`; sem Node/Python obrigatório no núcleo.

**Spec:** `docs/superpowers/specs/2026-09-05-os-empresa-v1-design.md`

## Global Constraints

- A demo é original e não copia arquivos do MazyOS.
- O núcleo funciona sem instalar packs opcionais.
- Clientes e projetos permanecem isolados; não sobrescrever entregas aprovadas.
- Toda ação externa sensível exige aprovação humana.
- O usuário não precisa conhecer nomes de arquivos para usar o sistema.
- Vídeo, anúncios, RTK, Ponytail e integrações entram somente no catálogo nesta entrega.
- O repositório de teste será privado no GitHub.
- Credenciais e arquivos `.env` nunca entram no Git.
