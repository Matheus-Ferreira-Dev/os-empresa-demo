# Comece aqui

## 1. Escolha o modo

- **Meu Negócio:** para organizar o marketing e a operação da própria empresa.
- **Prestador/Agência:** para gerenciar vários clientes sem misturar contextos.

Registre a escolha em `sistema/configuracao.md`.

## 2. Crie a primeira estrutura

Peça ao agente: `crie um cliente chamado [nome]` e depois `crie um projeto de [objetivo] para esse cliente`.

Os dados ficam em:

```text
clientes/<cliente>/cliente.md
clientes/<cliente>/projetos/<projeto>/projeto.md
clientes/<cliente>/projetos/<projeto>/entregas/
```

## 3. Gere uma entrega

Exemplos:

- `crie um carrossel sobre [tema] para o projeto atual`;
- `crie uma landing page para [oferta]`;
- `mostre o painel dos projetos`;
- `sugira uma skill para esta tarefa repetitiva`.

Toda entrega deve ter versão, checklist e status. Nada é publicado sem sua aprovação explícita.

## 4. Mantenha o contexto limpo

Trabalhe em um projeto por vez. O agente deve ler o manifesto do cliente e do projeto antes de criar arquivos e registrar decisões importantes no próprio projeto.
