# Clientes e projetos

Para um cliente, crie `clientes/<slug>/cliente.md` a partir de `templates/cliente.md`. Para um projeto, crie `clientes/<cliente>/projetos/<slug>/projeto.md` e a pasta `entregas/`.

Antes de gravar, valide nome, objetivo e cliente. Em modo `Prestador/Agência`, nunca use uma pasta compartilhada entre clientes. Liste os projetos lendo os manifestos, mostrando status, última entrega e próxima ação. Preserve arquivos existentes e incremente versões.
