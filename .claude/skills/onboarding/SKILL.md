# Onboarding

Leia `COMECE-AQUI.md` e `sistema/configuracao.md`. Se o modo ainda não estiver definido, explique `Meu Negócio` e `Prestador/Agência` e peça uma escolha. Depois crie o cliente e o projeto usando os templates, sem apagar dados existentes. Finalize mostrando os caminhos criados e a próxima ação.
